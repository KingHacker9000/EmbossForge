# EmbossForge

[![CI](https://github.com/KingHacker9000/EmbossForge/actions/workflows/ci.yml/badge.svg)](https://github.com/KingHacker9000/EmbossForge/actions/workflows/ci.yml)

**Open-source parametric paper embossing: artwork in, matched male/female dies out.**

EmbossForge is building a reusable 3D-printed embossing system with interchangeable dies. The project combines Python, OpenSCAD, and CadQuery so artwork and mechanical dimensions remain reproducible instead of living only in hand-edited mesh files.

## Project status

The core die concept is now **physically validated** on the target printer.

On 2026-09-07, a 16 mm butterfly male/female pair generated by EmbossForge was printed on a FlashForge Adventurer 5M with a 0.4 mm nozzle and successfully embossed ordinary notebook paper. See [`docs/PHYSICAL_VALIDATION.md`](docs/PHYSICAL_VALIDATION.md).

The reusable press and cartridge system remain prototype hardware and still require physical fit/motion/strength validation.

Current capabilities include:

- SVG and raster artwork input
- normalization of tricky SVG coordinate origins
- raster-to-vector tracing
- automatic matched male/female dies
- configurable paper thickness, relief, cavity depth, and XY clearance
- keyed die carriers for deterministic orientation
- OpenSCAD and STL die output
- low-filament smoke tests and calibration pieces
- parametric CadQuery cartridges, receivers, and lever press
- STEP/STL mechanical export
- generated assembly/hardware manifests
- open/closed solid collision checks
- Blender assembly import for visual QA
- GitHub Actions CI

## Fastest way to try it

Reference development environment: Python 3.11.

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -e ".[cad,dev]"

embossforge doctor
pytest -q
```

For a tiny, already-validated first print:

```powershell
embossforge butterfly-test
```

Then load both generated STLs at 100% scale:

```text
build/butterfly-test/micro_butterfly_male.stl
build/butterfly-test/micro_butterfly_female.stl
```

See [`docs/FIRST_PRINT.md`](docs/FIRST_PRINT.md) before printing.

## Generate your own die

```powershell
embossforge die examples\embossforge_mark.svg
```

Or use a PNG/JPG/BMP/TIFF/WEBP input:

```powershell
embossforge die my_logo.png --diameter 42 --paper-thickness 0.10
```

Typical output:

```text
build/<design>/
├── <design>_normalized.svg
├── <design>_male.scad
├── <design>_female.scad
├── <design>_male.stl
├── <design>_female.stl
└── <design>_manifest.json
```

The female die is not an exact negative. EmbossForge adds configurable lateral and depth clearance for the paper and accounts for the upper-die installation orientation.

See [`docs/ARTWORK_GUIDE.md`](docs/ARTWORK_GUIDE.md) for artwork constraints and debugging guidance.

## Spend filament in the right order

EmbossForge deliberately provides progressively more expensive tests:

```text
embossforge butterfly-test   # tiny real emboss smoke test
embossforge fit-coupon       # tiny cartridge rail/receiver clearance test
embossforge calibrate        # clearance + emboss matrices
embossforge mini-test        # reduced functional press
embossforge mechanics        # full V0.2 mechanical prototype
```

Do not use a successful miniature as proof of full-size strength. Small prints validate geometry, fit, motion, and light embossing only.

## Mechanical platform

`embossforge mechanics` generates the current V0.2 press pack in `build/mechanics/`.

The design currently uses:

- a printed base and side cheeks
- two smooth steel guide rods
- a sliding upper platen
- universal upper/lower cartridge receivers
- keyed interchangeable die inserts
- a lever with a transverse contact roller
- physical stop sleeves
- an M6-class main pivot and M5-class roller pin

Unique printed parts fit within the FlashForge Adventurer 5M build envelope. Exact hardware dimensions come from the generated `mechanics_manifest.json`, not from copied documentation numbers.

The generator also checks the open and nominally closed CadQuery assemblies for unintended printed-part intersections before accepting the mechanical pack.

## Tool architecture

EmbossForge uses each tool for what it is good at:

- **Python** — CLI, artwork processing, validation, profiles, automation
- **OpenSCAD** — deterministic 2D-artwork relief and calibration geometry
- **CadQuery** — parametric mechanical CAD and STEP/STL exports
- **Blender** — visual QA, ergonomics, presentation, and assembly inspection

Blender is intentionally not the dimensional source of truth. Generated meshes should not be hand-edited instead of changing the parametric source.

## Target printer

Primary development target:

- FlashForge Adventurer 5M
- 220 × 220 × 220 mm build volume
- 0.4 mm nozzle for prototype development
- 0.25 mm nozzle planned for fine-detail work

Printer-sensitive tolerances are calibration values, not universal constants.

## Safety

The current press is prototype hardware. Printed plastic can fail suddenly under load. Keep fingers away from the die gap, begin with low forces, inspect pivots/stops before use, and wear eye protection during early mechanical testing.
