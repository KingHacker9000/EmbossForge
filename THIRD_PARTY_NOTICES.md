## OpenSCAD

Official Windows desktop bundles include an unmodified OpenSCAD runtime so users can generate STL files without separately installing OpenSCAD. OpenSCAD is a separate project distributed under its own open-source license. The portable bundle preserves the license/notices shipped with the OpenSCAD distribution.

Project: https://openscad.org/
Source: https://github.com/openscad/openscad

## Qt for Python / PySide6

The EmbossForge desktop interface uses Qt for Python (PySide6). Qt for Python is distributed under its own licensing terms. Release builds use the upstream PyPI packages without modifying their library code.

Project: https://doc.qt.io/qtforpython-6/
